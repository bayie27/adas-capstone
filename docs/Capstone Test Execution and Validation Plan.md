# **Purpose**

_This document records the testing and validation activities completed for ADAS and the evidence used to assess readiness for final evaluation and organizational acceptance. It identifies the tested scope, environments, participants, schedule, evaluation methods, success criteria, and documentary evidence used to assess functional correctness, detection behavior, latency, performance, fault recovery, backup and restore safety, access control, auditability, usability, and organizational acceptance. Results are qualified where they use demonstration hardware, simulated fault injection, accelerated endurance windows, archival model evidence, or reconstructed timing. The application and AI components ran on one Windows ADAS host within a private three-device LAN; the record does not establish production-scale capacity or a completed live CDRRMO deployment._

## **Model and Inference Configuration**

| Item                               | Value                                                                                                                                                                                                                                                                                                                                                                                    |
| :--------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Architecture**                   | YOLO26n (Ultralytics, nano; COCO-pretrained)                                                                                                                                                                                                                                                                                                                                             |
| **Trained checkpoint**             | ai\_engine/epoch50.pt, epoch 50, dated August 9, 2026; trained at imgsz=640, batch size 64, with a 60-epoch run and patience 15\.                                                                                                                                                                                                                                                        |
| **Deployed build**                 | TensorRT engine exported from epoch50.pt with dynamic=True, batch=10, and half=True (FP16). The adopted epoch50.engine was built on the demonstration GPU host; engines are not portable across GPUs and fifteen-camera qualification is deferred.                                                                                                                                       |
| **Inference image size**           | 640                                                                                                                                                                                                                                                                                                                                                                                      |
| **Detection confidence threshold** | 0.15                                                                                                                                                                                                                                                                                                                                                                                     |
| **Detected class**                 | Class 0: accident, the only class that triggers alerts. Class 1: vehicle is a training foil and is discarded during inference.                                                                                                                                                                                                                                                           |
| **Temporal accumulation**          | Detections must accumulate corroborating evidence over time before an alert is raised; a single frame cannot trigger an alert. Per-camera accumulator with no tracker. IoU link `0.30`, evidence threshold `1.0` confidence-seconds, decay `0.30` per second, and EMA box smoothing `0.5`. It resets after reconnect/resume/restart or a processed-frame gap greater than `0.5` seconds. |

**Acceptance Criteria**  
The criteria below are the approved acceptance rules used to interpret the recorded results. A criterion is not considered proven when the underlying row is only simulated, duration-accelerated, archival, or otherwise qualified; those limitations remain part of the result.

| Item                              | Success Criterion                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| :-------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Unit Testing                      | 100% of executed unit tests pass. Anything less is treated as a build defect blocking further activity, not as a test result.                                                                                                                                                                                                                                                                                                                                                  |
| Integration Testing               | 100% of executed integration tests pass.                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| System / End-to-End Testing       | ≥95% of system test cases pass, with zero open Critical or Major defects.                                                                                                                                                                                                                                                                                                                                                                                                      |
| AI Model Validation — primary     | mean average precision at IoU 0.50 ≥ 0.85, measured on the validation split.                                                                                                                                                                                                                                                                                                                                                                                                   |
| AI Mod el Validation — supporting | Event-level recall and false alarms per minute are reported separately for standard and hard clips against the frozen checkpoint baseline, with TensorRT artifact, cadence, and source-resolution differences disclosed. The current reference run records standard recall 8/10, hard recall 0/6, overall 8/16, and 0.27 false positives/minute over 11.0 clean minutes; this is descriptive, project-specific evidence rather than an independent held-out test-set estimate. |
| Inference latency                 | The ≤100 ms per-frame target is measured against the declared model artifact and actual stream profile, with the timing definition and hardware recorded. A missing-artifact or capacity-only measurement is supporting evidence, not a deployed TensorRT result.                                                                                                                                                                                                              |
| Frame rate                        | The accepted operating band is 5–15 FPS per connected stream, with 15 FPS as the target and rates below 5 FPS as the warning floor. The larger-scale measurement is reported separately as a documented ceiling, not as the operational criterion.                                                                                                                                                                                                                                                                                           |
