## Which source to use

[CLAUDE.md](../CLAUDE.md) owns repository conventions and [CONTRIBUTING.md](../CONTRIBUTING.md) owns contribution commands and migration workflow. Current code, schemas and tests establish implemented behavior; active guides explain it. Archived plans are historical evidence, not authorization or instructions for new work.

Live defense and validation artifacts are listed in [CLAUDE.md](../CLAUDE.md#live-google-drive-resources). Local snapshots do not establish their current state. Follow the [paper-sync procedure](../paper_sync/PROCEDURE.md) for claim-bearing changes.
